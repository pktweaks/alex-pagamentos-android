# ALEX PAGAMENTOS Android

Aplicativo Android local-first para cadastro e controle de clientes.

## Funções
- Cadastro de clientes e cobranças recorrentes: 7 dias, 15 dias, mensal, única ou personalizada.
- Funciona offline e salva automaticamente no celular.
- Backup local diário.
- Compartilhar backup pelo WhatsApp.
- Gerar PDF dos clientes e compartilhar pelo WhatsApp.
- Notificações de vencimento e som especial para cliente atrasado.
- Ligar para o cliente pelo discador do Android.
- Anotações.

## Build
O GitHub Actions gera `ALEX-PAGAMENTOS.apk` automaticamente a cada push na branch `main`.
